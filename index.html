Descarga Aceslan para Android

Accede a la aplicación oficial desde tu dispositivo Android.
Escanea el QR o pulsa el botón para descargarla.

Descargar app

Disponible para dispositivos Android. Al descargar el APK, es posible que Android solicite permiso para instalar aplicaciones externas.

Cómo instalar

  1. 1 Pulsa en “Descargar app”.
  2. 2 Abre el archivo descargado.
  3. 3 Permite la instalación si Android lo solicita.
  4. 4 Pulsa en instalar.
