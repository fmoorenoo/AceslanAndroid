# Aceslan Android

Este repositorio contiene la página web desde la que se puede descargar el archivo APK de **Aceslan** para dispositivos Android.

El código fuente de la aplicación Android se encuentra en un **repositorio privado** y no forma parte de este repositorio público.

## Estado del proyecto

**La aplicación no se encuentra actualmente en funcionamiento**, ya que está pendiente de que el **Consorcio de Seguridad y Emergencias de Lanzarote** decida si continúa adelante con el proyecto.
