# ACESLAN · Android

**ACESLAN** es un proyecto de aplicación móvil orientado a mejorar la comunicación entre la ciudadanía y los servicios de seguridad y emergencias de **Lanzarote y La Graciosa**.

La aplicación se presentó públicamente en **mayo de 2026**, en versión beta, como resultado de una colaboración entre el **Consorcio de Seguridad y Emergencias de Lanzarote** y alumnado del **CIFP Zonzamas** de distintas especialidades formativas.

## ¿Qué propone ACESLAN?

Según la información difundida durante su presentación, el proyecto contempla:

- **Comunicación de incidencias:** envío de avisos sobre posibles riesgos, acompañados de imágenes y ubicación.
- **Alertas y recomendaciones:** difusión de información de interés para la seguridad y la autoprotección.
- **Noticias y comunicados:** un canal de información relacionado con los servicios de seguridad y emergencias.
- **Contacto directo:** una vía de comunicación entre usuarios y los servicios correspondientes.


## Sobre este repositorio

Este repositorio contiene la **página web para descargar el archivo APK de ACESLAN** e instalar la aplicación en dispositivos Android.

El **código fuente de la aplicación** se encuentra en un **repositorio privado** y no está incluido aquí.

## Estado actual

**ACESLAN no se encuentra actualmente en producción.** Su continuidad está pendiente de que el **Consorcio de Seguridad y Emergencias de Lanzarote** decida si sigue adelante con el proyecto.
